# plugins/notara-mac-window

This plugin updates the macOS window appearance based on the background color brightness.
This sets NSAppearanceNameVibrantLight for light backgrounds and NSAppearanceNameVibrantDark for dark backgrounds, which tells macOS how to render native controls like traffic lights.
